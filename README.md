# MEA CS Application v1.0.0

แอปบริการลูกค้า (PWA) สำหรับเจ้าหน้าที่การไฟฟ้านครหลวงที่ใช้รถยนต์ไฟฟ้า ให้บริการโดย บจก. สมาร์ท เทอร์มินอล คอร์ปอเรชั่น

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | แอปทั้งหมด (สร้างจาก `src/` ด้วย `python3 build.py`) |
| `manifest.json`, `sw.js` | PWA ติดตั้งบนหน้าจอโฮม iOS/Android |
| `assets/` | โลโก้ MEA/SMART, ตัวละคร AI, ภาพพื้นหลัง, ไอคอน |
| `vercel.json` | header สำหรับ Vercel |
| `db/` (ไม่ขึ้น GitHub) | SQL: `MEA_CS_setup.sql` (ติดตั้งครั้งเดียว รันซ้ำได้), `03_import_vehicles_template.sql` |
| `supabase/functions/cs-ai` | Edge Function AI CS Agent (Claude API) |

## ระบบหลังบ้าน
- Supabase โปรเจกต์ **MEA CS** (Org CS Application) `https://tfyhyrmbrqvitqnewzzv.supabase.co`
- หน้าเว็บใช้ publishable key เท่านั้น · ไม่ใช้ Supabase Auth · ทุกตารางเปิด RLS ไม่มีสิทธิ์ตรง
- เรียกได้เฉพาะฟังก์ชัน `cs_*` (security definer) ที่ตรวจ token และสิทธิ์รายรถ/บทบาททุกครั้ง
- ข้อมูลสำคัญใช้ Soft Delete · ทุกการบันทึกลง `cs_audit`
- AI: Edge Function `cs-ai` (verify_jwt ปิด — ตรวจ token เอง) Secret `ANTHROPIC_API_KEY` · เลือกรุ่นด้วย `CS_AI_MODEL` (ค่าตั้งต้น claude-sonnet-5-5) · จำกัด 60 ข้อความ/ชม./คัน · AI อ่านข้อมูลได้อย่างเดียวและส่ง "ร่าง Ticket" ให้ผู้ใช้ยืนยันเอง

## บทบาท
| บทบาท | สิทธิ์ |
|---|---|
| ผู้ใช้รถ (Vehicle User) | รถของตัวเองเท่านั้น: แจ้งบริการ ติดตาม ยืนยันผล ขอนัด PM รถสำรอง เอกสาร ข้อความ |
| ผู้ประสานงาน กฟน. (Coordinator) | รถทุกคันในหน่วยงานของตน (สลับรถได้) |
| SMART CS Operator | ทุกคัน · อัปเดต Ticket/นัด · อนุมัติรถสำรอง · เอกสาร · ตอบข้อความ |
| Service Manager | + ลบเอกสาร/รายการ PM · จัดการรถ · Audit Log |
| Technician | อัปเดตงาน · บันทึกผล PM/CM |
| System Admin | ทั้งหมด + บัญชีผู้ใช้ · ตั้งค่าช่องทางติดต่อ/รุ่นรถ · ยกเลิกรถ |

## เริ่มใช้งานจริง (ข้อมูลจริงเท่านั้น — ระบบไม่มีข้อมูลจำลอง)
1. เข้าระบบ admin → บัญชี › ความปลอดภัย › เปลี่ยนรหัสผ่าน
2. บัญชี › ตั้งค่าช่องทางติดต่อ — ใส่เบอร์ SMART CS / สายด่วน / LINE / อีเมล
3. บัญชี › จัดการรถ — ลงทะเบียนรถทั้ง 36 คัน (หรือใช้ `db/03_import_vehicles_template.sql`)
4. บัญชี › บัญชีผู้ใช้ — สร้างบัญชีเจ้าหน้าที่ SMART และผู้ประสานงานแต่ละหน่วยงาน
5. เลือกรถ › บำรุงรักษา — ลงแผน PM · เอกสารรถ — อัปโหลดใบส่งมอบ ประกัน พ.ร.บ. คู่มือ
